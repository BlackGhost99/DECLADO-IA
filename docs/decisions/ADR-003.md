# ADR-003 : Moteur de calcul déterministe et règles versionnées

Statut : Accepté, à implémenter lot 4.

## Décision

Calcul en Decimal, règles bornées (pas d'eval), profils fiscaux publiés immuables, total absent si incomplet.

## Remarques

Taux inconnu ≠ zéro ≠ exonéré ≠ non applicable.

Référence : `docs/specifications/02-conception-technique.md` §14.
