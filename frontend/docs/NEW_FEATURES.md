## 🎨 Fonctionnalités Ajoutées

- **Général**:

  - Traitement automatique après import

  - Devise par défaut (FCFA, USD, EUR, GBP, CNY)
  - Gestion des taux de change personnalisés
  - Conversion automatique des montants

- **Thème**:
  - Thème sombre (Dark) - Par défaut
  - Thème clair (Light)
  - Thème personnalisé (Custom) - À venir

- **Avancé**:
  - Répertoire de sauvegarde
  - Format d'export par défaut
  - Export/Import des paramètres
  - Réinitialisation des paramètres

### 2. 🛠️ Panneau d'Outils

**Accès**: Bouton FAB en bas à droite → 🛠️

**Outils disponibles**:

#### 💱 Convertisseur de Devise
- Conversion en temps réel entre devises
- Affichage des résultats pour toutes les devises
- Utilise les taux configurés dans les paramètres

#### 📊 Calculatrice Douanière
- Calcul rapide des droits et taxes
- Entrée: Valeur CIF, Taux DD, Taux TVA
- Calcul automatique des montants

#### 📐 Calculateur de Taux
- Fonctionnalité à venir

### 3. 👁️ Prévisualisation des Fichiers

**Fonctionnalités**:
- **Images**: Affichage direct avec overlay d'informations
- **PDFs**: Aperçu avec informations (nombre de pages, CER)
- **Autres formats**: Icône et informations du fichier
- **Extrait OCR**: Affichage du texte extrait (première page)

**Tailles disponibles**:
- Petite (200x200px)
- Moyenne (400x400px) - Par défaut
- Grande (600x600px)

**Configuration**: Paramètres → Général → Taille de prévisualisation

### 4. 💱 Gestion des Devises

**Fonctionnalités**:
- Conversion automatique des montants selon la devise sélectionnée
- Formatage selon les standards internationaux
- Taux de change personnalisables
- Support de 5 devises: FCFA, USD, EUR, GBP, CNY

**Utilisation**:
- Les montants dans les calculs douaniers sont automatiquement convertis
- Utilisez le panneau d'outils pour des conversions rapides
- Configurez les taux dans Paramètres → Devises

### 5. 🎨 Système de Thèmes

- **Custom** (Personnalisé): À venir - Personnalisation complète

**Changement de thème**: Paramètres → Thème → Sélectionner un thème

## 🚀 Utilisation

### Accéder aux Paramètres
1. Cliquez sur le bouton ⚙️ en bas à droite
2. Naviguez entre les onglets (Général, Devises, Thème, Avancé)
3. Modifiez les paramètres selon vos besoins
4. Les changements sont sauvegardés automatiquement

### Utiliser les Outils
1. Cliquez sur le bouton 🛠️ en bas à droite
2. Sélectionnez l'outil désiré
3. Utilisez le convertisseur de devise ou la calculatrice
4. Fermez le panneau en cliquant à l'extérieur

### Prévisualiser un Fichier
1. Sélectionnez un document dans la liste
2. L'onglet "👁️ Aperçu" apparaît automatiquement (si activé)
3. Visualisez l'image, les infos PDF ou l'extrait OCR
4. Changez la taille dans Paramètres → Général

### Changer de Devise
1. Ouvrez Paramètres → Devises
2. Sélectionnez la devise par défaut
3. Ajustez les taux de change si nécessaire
4. Tous les montants seront automatiquement convertis

## 💾 Sauvegarde

- **Paramètres**: Sauvegardés automatiquement dans `localStorage`
- **Export**: Paramètres → Avancé → Exporter les paramètres
- **Import**: À venir

## 🔄 Synchronisation

Les paramètres sont stockés localement dans le navigateur. Pour synchroniser entre appareils, utilisez l'export/import des paramètres.
