# ADR-004 : Sources brutes immuables, observations distinctes des décisions

Statut : Accepté, à implémenter lots 1–3.

## Décision

Originaux, extractions, corrections et décisions sont des objets séparés ; les corrections sont append-only.

## Remarques

Le journal d'audit du lot 0 applique déjà ce principe (append-only en base).

Référence : `docs/specifications/02-conception-technique.md` §14.
