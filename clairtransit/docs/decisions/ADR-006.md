# ADR-006 : Calcul et validation liés à une empreinte de révision

Statut : Accepté, à implémenter lots 4–5.

## Décision

Chaque objet mutable porte `row_version` ; une version périmée renvoie 409. L'approbation référencera l'empreinte exacte des données et du calcul.

## Remarques

Le verrou optimiste est implémenté et testé au lot 0 sur les importateurs et les affiliations.

Référence : `docs/specifications/02-conception-technique.md` §14.
