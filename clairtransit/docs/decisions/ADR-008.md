# ADR-008 : Fournisseur IA interchangeable, envoi minimal, sorties contrôlées

Statut : Accepté, à implémenter lot 3.

## Décision

Interface `extract_document`, `enrich_goods_description`, `rank_candidates`, `explain_candidate` ; fonctionnement complet sans clé ; contenu des documents traité comme donnée, jamais comme instruction.

## Remarques

Les substituts de développement seront identifiables et non présentés comme une IA opérationnelle.

Référence : `docs/specifications/02-conception-technique.md` §14.
