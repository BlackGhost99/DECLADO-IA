# ADR-001 : React/Django/PostgreSQL, monolithe modulaire

Statut : Accepté (lot 0).

## Décision

Interface React/TypeScript, API Django/DRF, PostgreSQL source de vérité, Celery/Redis pour les travaux longs. Un seul déploiement backend découpé en applications Django (`apps/*`) sans dépendance circulaire.

## Remarques

Django 5.2 LTS retenu plutôt que 6.x pour la durée de support (avril 2028) et la compatibilité DRF 3.18. Redis ne détient aucune donnée métier irremplaçable.

Référence : `docs/specifications/02-conception-technique.md` §14.
