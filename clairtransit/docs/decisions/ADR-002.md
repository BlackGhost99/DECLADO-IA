# ADR-002 : Extraire et contrôler les codes présents avant toute proposition

Statut : Accepté, à implémenter lots 2–3.

## Décision

Le code lu sur la facture est conservé tel quel, avec son champ source, puis contrôlé. Une proposition n'est produite que si le code est absent, incomplet, ambigu, incohérent, ou sur demande.

## Remarques

Une référence fournisseur n'est jamais assimilée automatiquement à un code douanier. Aucune complétion par des zéros.

Référence : `docs/specifications/02-conception-technique.md` §14.
